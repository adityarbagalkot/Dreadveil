# Dreadveil UI References

Approved visual mockups and design references for **Dreadveil Adventures**.

## Purpose
This repository is reserved for approved UI mockups, screen references, and design notes. It is separate from the game implementation repository.

## Design direction
- Theme: The Forbidden Manuscript — gothic dark fantasy, ruined cathedral, crimson eclipse, occult relics, and tactile materials.
- Materials: aged parchment, engraved metal, stone, leather, candles, and textured dice.
- Palette: Obsidian `#11100F`, Vellum `#D6C7A5`, Tarnished Gold `#B18A48`, Blood Wine `#762F32`, Rotten Green `#52664B`, Bone Grey `#A8A7A0`.
- Avoid modern dashboard styling, neon colors, excessive skull motifs, and decorative clutter that reduces readability.

Only mockups explicitly approved by the project owner should be added as canonical references. Keep each screen in its own folder and preserve approved assets unchanged.

## Repository boundary
Do not place game source code here. Do not modify the `Dreadveil-Adventures` implementation repository as part of UI design work.
